# Sistema de Gestión de Biblioteca (Trabajo Práctico Integrador)

Aplicación web full stack desarrollada con arquitectura modular por funcionalidad.

## Tecnologías Principales
- **Backend**: Node.js, Express, TypeScript, TypeORM, SQLite, JWT, bcrypt.
- **Frontend**: React, JavaScript, Vite, React Router, Axios, Yup, Tailwind CSS.

## Estructura de Entrega
- `/backend`: Servidor API RESTful modular.
- `/frontend`: Aplicación cliente React modular.
- `/docs`: Documentación técnica completa (Instalación, Arquitectura, Endpoints, Pruebas).
